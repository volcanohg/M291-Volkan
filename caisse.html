Kiosque du Paléo

Lisez le script à droite. Écrivez votre prédiction. Ensuite seulement, faites les clics du scénario. Rechargez la page entre chaque scénario.

La caisse

Aujourd’hui : code PALEO — le plateau revient à zéro.

Plateau

Total

0 CHF

Le script (celui qui tourne vraiment)

let total = 0;

function montrer() {
  document.getElementById("affiche").textContent = total + " CHF";
}

document.getElementById("frites").addEventListener("click", function () {
  total = total + "6";
  document.getElementById("panier").textContent =
    document.getElementById("panier").textContent + "Frites ";
  montrer();
});

document.getElementById("boisson").addEventListener("click", function () {
  total = total + "4";
  document.getElementById("panier").textContent =
    document.getElementById("panier").textContent + "Boisson ";
  montrer();
});

document.getElementById("promo").addEventListener("click", function () {
  const code = document.getElementById("code").value;
  if (code === "paleo") {
    total = 0;
    document.getElementById("panier").textContent = "";
    montrer();
  }
});

document.getElementById("vider").addEventListener("click", function () {
  document.getElementById("panier").textContent = "";
  document.getElementById("affiche").textContent = "0 CHF";
});

Les 4 scénarios

  1. Un clic sur Frites. Que lit-on dans Total ?
  2. Frites, puis Boisson. Que lit-on dans Total ?
  3. Frites, puis vous tapez PALEO comme sur l’affiche, puis Appliquer. Le total revient-il à 0 ?
  4. Frites, puis Vider le plateau, puis Frites à nouveau. Que lit-on dans Total ?
