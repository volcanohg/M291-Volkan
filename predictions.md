## Extrait 1 — Afficher
* **Prédiction :** Je pense que l'écran / la console va montrer : `Bonjour la classe`
* **Explication :** Le code écrit directement le texte "Bonjour la classe" dans l'élément HTML avec l'ID `out1`.

* **Prédiction :** Je pense que l'écran / la console va montrer : `7`
* **Explication :** Le code fait une addition : il additionne la variable `a` (4) et la variable `b` (3) pour afficher le résultat (7).

* **Prédiction :** Je pense que l'écran / la console va montrer : `3`
* **Explication :** La propriété `.length` compte le nombre d'éléments dans le tableau `fruits` (pomme, poire, kiwi).

## Extrait 4 — Condition
* **Prédiction :** Je pense que l'écran / la console va montrer : `suffisant`
* **Explication :** La note est 5. Comme 5 est plus grand ou égal à 4 (`note >= 4`), le programme choisit le texte "suffisant".

## Extrait 5 — Boucle simple
* **Prédiction :** Je pense que l'écran / la console va montrer : `1 2 3 `
* **Explication :** La boucle `for` répète l'action 3 fois. Elle ajoute les nombres de 1 à 3 avec un espace après chaque nombre.
