Contrôle de votre fichier JSON

Cette page vérifie deux choses : que le fichier est écrit correctement, puis que toutes les fiches portent les mêmes étiquettes. Rien n'est envoyé sur Internet.

  1. Dans VS Code, cliquez dans votre fichier .json, sélectionnez tout (Ctrl + A, ou Cmd + A sur Mac), puis copiez.
  2. Cliquez dans la grande zone ci-dessous et collez.
  3. Cliquez sur « Contrôler ». Lisez le premier message, corrigez dans VS Code, enregistrez, puis recommencez.
Outil fourni pour la semaine 10 du module ICT 291. Il ne remplace pas votre relecture : il ne sait pas si vos fiches sont crédibles.
